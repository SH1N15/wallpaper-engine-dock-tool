壁纸 Dock 工具使用说明

这是一个给 Wallpaper Engine 场景壁纸添加 Dock 栏的工具。添加的 Dock 支持悬停放大、点击启动程序、拖拽排序。原壁纸不会被修改，结果会作为新壁纸（原名后加 _Dock）安装到 Wallpaper Engine 的已安装列表中。

使用方法
========

把壁纸项目文件夹拖到「添加Dock.bat」上，等待运行完成；也可以在命令行运行：

    python dock_tool.py 壁纸目录

完成后打开 Wallpaper Engine，选择新生成的壁纸即可。工坊壁纸的目录位于 Steam 安装目录下的 steamapps\workshop\content\431960\ 中。

第一次使用需要在壁纸设置里给图标指定快捷方式：先选择图标序号，再点击对应的「指定快捷方式」。未指定的图标点击时只会弹跳，不会启动程序。

设置导入
========

如果已经有一个配置好的 Dock 壁纸，新壁纸可以直接继承它的设置，不用重新配置。在命令行加上 --from 参数：

    python dock_tool.py 壁纸目录 --from 已有Dock壁纸名

也可以把壁纸名写进工具目录的「设置来源.txt」，这样拖放壁纸文件夹时同样会自动导入设置。

参数说明
========

    --from  从指定的 Dock 壁纸导入设置（快捷方式、图标数量、大小、颜色等）
    --out   指定输出目录名，默认为 原标题_Dock
    --we    手动指定 Wallpaper Engine 安装目录（默认自动探测）

注意事项
========

1. 仅支持场景类壁纸。视频和网页壁纸没有 scene.json，无法添加。
2. 对同一个壁纸重复运行会覆盖上一次的结果。
3. dock_source 和 runtime 文件夹是工具的组成部分，拷贝时请随文件夹一起带走，不要删除。
4. Dock 默认显示在屏幕下方居中，可以拖动到其他位置，位置会被自动记住。竖版壁纸会自动计算位置，不会被屏幕裁掉。
5. Dock 栏原作者为 seekay（创意工坊 3573886911），允许个人使用与分享，禁止商用。
